# 表紙を作る（KDPのペーパーバックとKindle）

表紙は、本文と同じく HTML と CSS で組める。AIがデザインの案を出し、言葉の直しを重ねて仕上げる。
実際の本（B5・約200ページ・カラー）の表紙を作った経験から。

## 大きさ

- ペーパーバックの表紙は、裏表紙・背・表表紙をつなげた1枚のPDF。
  - 幅 ＝ 裁ち落とし3.2mm ＋ 裏表紙 ＋ 背 ＋ 表表紙 ＋ 裁ち落とし3.2mm
  - 高さ ＝ 裁ち落とし3.2mm ＋ 判型の高さ ＋ 裁ち落とし3.2mm
- 背の幅 ＝ ページ数 × 紙の厚み（白黒・白い紙 0.0572mm、白黒・クリーム紙 0.0635mm、標準カラー 0.0572mm、プレミアムカラー 0.0596mm）。ページ数が変わると作り直し。表紙は、ページ数を引数にして作り直せるスクリプトにしておく。
- 向き：横書き（左綴じ）は、広げて左が裏表紙・右が表表紙。縦書き（右綴じ）は逆。
- 文字は仕上がりの線から3.2mm以上内側。背の文字は80ページ以上の本だけ、背の両端から1.6mm以上内側。
- バーコードは、KDPが裏表紙の右下（背の側）に自動で置く（約50.8×30.5mm、端から約6.35mm）。そこを空けておく。
- Kindleの表紙は、縦横比1:1.6の画像（推奨 1600×2560px）。表表紙のデザインを縦長に組み直して書き出す（帯を下端に付けたまま、書名と帯の間を広げる等）。丸めで1〜2pxずれるので、最後にちょうどの大きさに直す。WebPは使わない（`kindle.md`）。

- **著者から電子書籍用の表紙画像が届いた時**：大きさ・形式（拡張子と中身が違う事がある。例：.jpg なのに PNG）・色（RGB）を確かめる。KDPの最低は短い辺500px、推奨は 1600×2560px。足りない時は元のデータを頼むのが一番。急ぐ時は、2段階に分けて拡大し、そのたびに輪郭を補正（UnsharpMask）すると、単純な拡大よりは締まる（細部は増えない事を伝える）。紙の表紙と別の画像を電子書籍に使う時は、表紙を差し替える後処理で、PDFの1ページ目の代わりにその画像を使う。

## 組み方の注意

- **PDFは Chrome で作るとよい**：Vivliostyle（11.2）では、一部の書体（macOSに付属する書体を取り出した物等）が読み込まれず、別の書体で組まれた。Chrome のヘッドレスの印刷（`--print-to-pdf`、`--virtual-time-budget` で書体の読み込みを待つ）なら読み込まれた。待たないと文字が抜ける事がある。
- **寸法ちょうどにする**：Chrome は用紙の大きさを0.2mmほど丸める。作ったPDFを、求める寸法ちょうどのページに載せ直す（PyMuPDF の `show_pdf_page`）。
- **SVGの文字で縁取り**：白抜きの文字に縁と影を付けるなら、SVGの `<text>` を3枚重ねる（影・縁〈`stroke-linejoin: round` で角を丸める〉・中の白）。CSSの `-webkit-text-stroke` は角が尖る。二重の袋文字（黒い字・白い縁・紺の縁）も同じ方法。
- **吹き出し**：楕円としっぽを別の図形で描くと、つなぎ目に線が残る。1つの輪郭（`<path>` の楕円の弧＋しっぽ）で描く。
- **クラス名がぶつかる**：表表紙・裏表紙・背を1枚に組む時、同じクラス名（`.hon` 等）を使うと別の部分の指定が効いてしまう。部分ごとに接頭辞を付ける。

## 書体

- 表紙の書体は、販売する本への使用が許されているかを必ず確かめる。SIL OFL（Google Fonts の多く）は商用・埋め込み可。パソコンに付属する書体は規約により扱いが違う。有料の書体サービス（Adobe Fonts、モリサワ、フォントワークス等）は、表紙への使用を明記している物が多い。
- 再配布できない書体のファイルは、記録（git）に入れない。
- ポップな書体（Mochiy Pop One 等）は、使いすぎると安っぽく見える。表紙の主役の語だけに使うか、見出し用の太いゴシック（ヒラギノ角ゴ W9、Noto Sans JP Black 等）と組み合わせる。
- 会社やサービスのロゴは商標なので使わない（色だけで表す）。

## AIとデザインを詰める流れ

1. 方向の違う案を3つほど並べてもらう（一つずつより、並べた方が好みがはっきりする）。
2. 印象を言葉で伝える（「地味」「真面目すぎる」「安っぽい」「もっと緩急を」）。AIは配色・書体・文字の大小・飾りに置き換える。
3. 方向が決まってから細部を直す。案ごとの良い所を組み合わせて頼める。
4. 書体は、同じ表紙を書体だけ変えて並べて選ぶ。
5. 「間が開きすぎ」のような感覚の直しは、AIが寸法を測ってから直す。
6. 表表紙が決まったら、裏表紙（帯に主な章、特典、バーコードの場所）・背・Kindle用まで一式で作る。
