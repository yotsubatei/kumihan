## ビルドと確認（原稿・CSSを変えたら毎回）
1. `npm run build`（前処理でルビの書き方を検査し、後処理でEPUBをKindle向けに整える）
2. `qpdf --check {{SLUG}}.pdf`
3. `epubcheck {{SLUG}}.epub`（エラー・警告0件）
4. `python3 tools/kumihan-kit/check_kindle_epub.py {{SLUG}}.epub`
5. 総ページ数を前回の確認版と比べる。変わった時は理由を確かめ、説明に書く。

## CSSの注意点
- `custom.css` はPDFとEPUBで共有する。紙のページの大きさを前提にした値は `@media print` の中に書く。
- Kindle は `var()`・論理プロパティ（`margin-block` 等）・`:is()`・`unicode-range`・`leader()`・`calc()` を解釈しない。後処理が大半を直すが、新しく書く時は避けるか、直前に固定の値を書く。
- 縦書きでは `*-block-*` が左右、`*-inline-*` が天地、`text-align` が天地の揃えになる。

## 道具
- `tools/kumihan-kit/` は kumihan プラグインのスクリプトのコピー。更新を取り込む時は、コピーし直してから新旧の出力を見比べる。
